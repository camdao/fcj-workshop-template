### Week 4 Achievements:

* Mastered Amazon S3 fundamentals:
  * Understanding S3 storage architecture and concepts
  * Bucket and object hierarchy
  * S3 naming conventions and best practices
  * Strong consistency model and implications

* Learned about S3 storage classes:
  * S3 Standard for frequently accessed data
  * S3 Intelligent-Tiering for automatic cost optimization
  * S3 Standard-IA and One Zone-IA for infrequent access
  * S3 Glacier and Glacier Deep Archive for long-term archival
  * Cost and performance trade-offs

* Understood S3 lifecycle management:
  * Creating lifecycle policies
  * Transitioning objects between storage classes
  * Expiring objects automatically
  * Optimizing storage costs

* Successfully created and configured S3 buckets:
  * Created buckets with proper naming
  * Uploaded and organized objects
  * Configured storage classes based on access patterns
  * Set up lifecycle policies for cost optimization

* Mastered S3 security mechanisms:
  * Bucket policies for resource-based access control
  * IAM policies for identity-based access control
  * Access Control Lists (ACLs) - legacy method
  * Block Public Access settings
  * Understanding policy evaluation logic

* Implemented S3 encryption:
  * Server-Side Encryption with S3 (SSE-S3)
  * Server-Side Encryption with KMS (SSE-KMS)
  * Server-Side Encryption with Customer keys (SSE-C)
  * Encryption in transit (HTTPS/TLS)

* Learned S3 versioning and replication:
  * Enabling and managing versioning
  * Protecting against accidental deletion
  * Cross-Region Replication (CRR) for disaster recovery
  * Same-Region Replication (SRR) for compliance

* Gained practical experience with:
  * S3 static website hosting
  * Pre-signed URLs for temporary access
  * S3 event notifications
  * S3 access logging and monitoring

* Understood S3 performance optimization:
  * Multipart uploads for large objects
  * Transfer Acceleration
  * Request rate performance
  * Best practices for key naming

* Built foundational knowledge for advanced S3 features like S3 Select, S3 Batch Operations, and integration with other AWS services.
