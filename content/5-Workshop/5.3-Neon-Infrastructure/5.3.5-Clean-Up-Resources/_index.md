### 5.3.18. Clean Up Resources After the Lab

When the project is complete, follow this order to avoid incurring unnecessary costs:

1. Delete the RDS instance
2. Delete the DB Subnet Group
3. Delete the Parameter Group
4. Delete the associated Security Group
5. Delete any unused S3 buckets
